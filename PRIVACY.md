# Privacy

Google Search Tabs Keeper does not collect, store, sell, or transmit personal
data.

The extension reads the current Google Search page and its URL only to:

- detect whether Google's native search category tabs are visible;
- preserve the current search query when creating category links; and
- display a replacement navigation bar when needed.

All processing occurs locally in the browser. The extension has no analytics,
advertising, telemetry, account system, remote code, or external API requests.
